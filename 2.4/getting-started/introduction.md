# Introduction

[[toc]]

ls-lint is an extremely fast file and directory name linter. Define your project structure as code.
ls-lint finds misnamed and misplaced files and directories and gives your agents the right name and place before they even create new ones.

## Key facts

- Minimal setup with simple rules managed in one single or multiple `.ls-lint.yml` files
- Works for directory and file names - all extensions supported - full unicode support
- Ready for the agentic era - optional roles and MCP server for AI agents, fully backwards compatible
- Incredibly fast - lints thousands of files and directories in milliseconds
- Support for Windows, macOS and Linux + [NPM Package](https://www.npmjs.com/package/@ls-lint/ls-lint) + [GitHub Action](https://github.com/ls-lint/action) + [Homebrew](https://formulae.brew.sh/formula/ls-lint) + Docker
- Reliable since 2020 - 17M+ npm downloads and trusted by open source projects from [Ansible](https://github.com/ansible/ansible-hub-ui/blob/HEAD/.ls-lint.yml), [Buildkite](https://github.com/buildkite/docs/blob/HEAD/.ls-lint.yml), [ByteDance](https://github.com/web-infra-dev/garfish/blob/HEAD/.ls-lint.yml), [Huawei](https://github.com/DevCloudFE/vue-devui/blob/HEAD/.ls-lint.yml), [Philips](https://github.com/philips-software/amp-embedded-infra-lib/blob/HEAD/.ls-lint.yml), [Red Hat](https://github.com/pulp/pulp-ui/blob/HEAD/.ls-lint.yml), [Renovate](https://github.com/renovatebot/renovate/blob/HEAD/.ls-lint.yml) and many more
- Almost zero third-party dependencies in the cli - only [go-yaml](https://github.com/yaml/go-yaml) and [doublestar](https://github.com/bmatcuk/doublestar)
